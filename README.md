# olympia-data (temporary branch)

A GitHub Action that downloads open geodata for greater Olympia, WA for a personal driving-game project:

- OpenStreetMap roads, buildings, water, parks (© OpenStreetMap contributors, ODbL)
- USGS 3DEP elevation (public domain)
- Overture Maps buildings with heights (ODbL / CDLA, see Overture attribution)
- USDA NAIP aerial imagery (public domain)

This branch is unrelated to the project on `master` and can be deleted at any time.
